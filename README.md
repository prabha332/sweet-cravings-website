# 🍰 Sweet Cravings

A responsive bakery website built with HTML, CSS, and JavaScript.

## 🌐 Live Website

Visit the website:

https://prabha332.github.io/sweet-cravings-website/

## 📖 About

Sweet Cravings is a responsive bakery website designed to showcase bakery products, provide information about the bakery, and allow customers to place orders.

The website includes:

- 🏠 Home page
- 🍰 Bakery menu
- 📖 About page
- 📍 Contact page
- 🛒 Order page
- 📱 Responsive mobile navigation
- 🖼️ Bakery product images
- 📱 Mobile, tablet, and desktop layouts

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Media Queries
- Git
- GitHub Pages
